# Fix plan for the 24 Oct 2026 audit

Companion to `AUDIT-2026-10-24.md`; section letters (A1, B2 …) refer to it.

## The idea: fix each problem where the file is made

The 76 files come from four sources. Edit a file anywhere else and the next `export_all.sh` overwrites the fix.

| files | made by | so fix in |
|---|---|---|
| 15 page-file editions (Hegel, Wolff, Fries, Bardili …) | `corpus.py book`, from `_facing-pipeline/*/work` | `corpus.py` or the page files |
| Obereit, Dacqué, Klages *Persönlichkeit*, Trendelenburg ×3, 37 Vasconcelos | `corpus.py text` / `chunks` / `html`, from `originals/` and the PDFs | `corpus.py` or the source in `originals/` |
| 17 PDF-recovered editions (Rubio, Clavigero, Gamarra, Bachofen …) + Klages *Geist* | nothing (recovered once) | the corpus file itself |
| README, PROJECT-INSTRUCTIONS | `corpus.py index` / by hand | `corpus.py` / by hand |

A trap the audit turned up: the second group's headers say "THIS FILE IS THE SOURCE, corrections go here", but `export_all.sh` regenerates those files. A hand correction made there today would be lost on the next export. The header fix in step 2 deals with this.

Two kinds of fix need no model judgment, so they're done by script: generator bugs and mechanical cleanup. Only about ten individual passages need a person to look at them. No re-translation or re-review is planned, because the audit found no translation errors, only alignment, extraction and format faults.

## Steps

**1. Safety net (≈15 min).** Work on a branch. Save the audit checks as `tools/check_corpus.py`, one script that prints the counts from the audit. Record today's numbers as the baseline. Every later step must bring its counts down without raising any other count.

**2. Generator fixes in `corpus.py` (≈1 h). Fixes A1, A2 (page-file editions), B2, B3, B4.**
- **Hegel (A1).** The page OCR in `hegel-enz/work/ocr/` is correct; for example, `s192.txt` is p. 171 and matches the English. The fault is in `ocr_lines_geo`: it reads the German from the source PDF's text layer at a fixed `pdf_offset`, and from about scan 167 that offset no longer points to the right page. Fix: use the geometric path only when its text agrees with `ocr/sNNN.txt`, otherwise fall back to the OCR file. A simple word-overlap test is enough.
- **Folios (A2).** In `folio()`, when a page's folio breaks a steady +1 run (prev + 2 = next), use prev + 1 and log it. This covers Wolff (282 markers), Fries and Hegel. Correct the running heads in the Wolff page files too, so the web reader agrees.
- **Conventions line (B2).** Build it from the header fields instead of one fixed text, so it describes the file's actual shape. Write the correct "regenerated from … — correct the source, not this file" header for files made by `text`/`chunks`/`html`.
- **Front matter (B4).**
  - Fill the 3 empty years.
  - Set `title_en` for the Vasconcelos files: 30 short Spanish titles, translated in-line; the 7 English titles stay as they are.
  - Normalise year ranges to an en dash, and split "1859 (2nd ed. 1925)" into `year` + `edition`.
  - Stop quoting YAML values unless they need it.
  - Add an `author_sort` field so the two forms of Palágyi's name group together.
- **Volume prefix (B3).** Add a `--volumes` option so Fries vol. II writes `[p. II.8]`, as Exner already does.
- **README table.** Add a "review status" column (Klages *Geist* = unrevised).
- Then run `export_all.sh`.

**3. One cleanup script for the source-is-the-file group: `tools/cleanup_pdf_recovered.py` (≈1.5 h). Fixes A2 (rest), A3, B1 headings.** It is deterministic, runs once, prints a dry-run diff summary per file, and writes only when told to. In order:
1. Join a paragraph to the next when it ends without terminal punctuation and the next starts lowercase. Never join across a page marker or heading. Then rejoin `‐`/`-` line breaks.
2. Delete a catchword paragraph (1–2 words) when the same word starts the text after the next `[p. N]`.
3. Delete running-head and signature lines (wide internal spacing, plus the book's running title or a single capital letter).
4. Rejoin split drop caps (`W       herever`) and letter-spaced titles.
5. Convert bare folio lines (`— 166 —`) to `[p. 166]` (Bachofen: this gives it printed-page citations). Delete them elsewhere.
6. Apply the same folio interpolation as step 2 (Palágyi *Logik* 155 markers, Rubio, Luz, Gamarra, Vaz Ferreira).
7. Move `## ` headings out of the `>` blockquotes (Luz, Rubio, Vaz Ferreira).

**Check:** print 15 random joins and 15 random deletions per file, and read them. The risky rule is "lowercase start = continuation", because verse and lists can start lowercase. The sample will show whether a book needs that rule turned off.

**4. Fixes in the originals and HTML sources (≈20 min). Fixes A4 for the regenerated files.**
- Delete the Google boilerplate from the Dacqué extraction: an option in `corpus.py text` to drop pages that match it.
- Strip the margin OCR at Klages *Persönlichkeit* page breaks in `originals/klages-persoenlichkeit.md`.
- Restore the 40-odd broken `<sup>` cues in the Vasconcelos HTML readers with a regex pass, then re-export.

**5. Individual fixes (≈30 min). Fixes the rest of A4.**
- Brentano note 4/6 split: fix it in the page file.
- Bardili title-page line shift: fix it in the page file.
- Hegel p. 286 library slip and the Henríquez Ureña running heads: drop them in `corpus.py`, as running-head lines.
- Luz y Caballero p. 100: open the PDF page. If the English is cut there too, translate the missing half-sentence from the original; this is the only translation in the plan.
- Then scan the other PDF-recovered files for the same pattern: an English paragraph that ends mid-sentence with no page break after it. List the hits rather than fixing blind.

**6. Documentation (≈30 min). Fixes B1, B3, B5–B7.**
Rewrite the README conventions section and `PROJECT-INSTRUCTIONS.md` to cover:
- the five file shapes and what each marker kind means (`[p. N]`, `[p. II.N]`, `[scan N]`, `[PDF N]`);
- citing `[scan]`/`[PDF]` positions when no printed page is marked;
- "follow the glossary where one exists";
- "originals keep the long s (ſ): search both spellings";
- the review status;
- the current scope, which is not only Kant.

**7. Verify and publish (≈20 min).**
- Run `check_corpus.py` again; the A-section counts should fall to roughly zero.
- Run the § cross-check on every paired edition, then `reader.py corpus docs`, and look at Hegel p. 171, a Clavigero page, a Wolff page and Bachofen in the local reader.
- Commit and show the diff summary. Push only on your OK, since a push redeploys the site.

## Left out on purpose
- **Glossaries for the 18 editions without one (B5).** That means reading each translation for its term decisions: real cost (~1–2M tokens per book with agents), and nobody has asked for those terms. Step 6 rewords the instructions instead. Do individual ones when someone starts working on that book.
- **Translating the quotations left in Latin or Italian (B6).** This is a policy decision first. Write the policy in step 6, and apply it only when a book is next revised.
- **Correcting or re-OCRing the originals (C).** Rubio and Bardili would need new OCR (Fraktur and early Latin type), a separate, larger job. The scans stay the authority, as the headers already say.
- **No new framework.** One check script, one cleanup script, a handful of `corpus.py` changes.

## Projected cost
- **Model work:** about 3–5 hours in one session at normal effort, with no subagents. Steps 2–5 are writing and running scripts; the 56 MB corpus is processed locally in Python, and the model reads only diffs, samples and logs.
- **Tokens:** roughly 4–8M input tokens (mostly cache reads of a growing context) and 80–150k output tokens. For scale, one translated book cost tens of millions of tokens, and Bolzano at max effort about 170M. This plan is a few percent of one book.
- **What would multiply the cost:**
  - running it at max/xhigh effort;
  - sending agents to review the reflowed books page by page (each book would cost millions of tokens; the samples are enough);
  - glossary building.

  None of these is planned.
- **Your time:** about 15 min. Approve the branch work, look at the reflow samples for 2–3 books, and approve the push.
- **Change to the shared skill:** steps 2 and 4 edit `corpus.py` in the side-by-side-translation skill. The research team's copies need the updated skill before they run `export_all.sh`, or their next export brings the old faults back. I'll ask before repackaging the skill.
