# Bardili, *Grundriß der Ersten Logik* (Stuttgart 1800) — glossary (BINDING)

Christoph Gottfried Bardili (1761–1808): anti-Kantian "rational realism" (Reinhold's term, which he took up
in 1800). The book is polemical, ironic, compressed, full of Latin school terms and private symbols
(A, C, B, b, x, y, +, −, fractions). Translate **literally and consistently**: the argument lives in the
repetition of exact formulas. Never smooth a formula into prose, never "explain" it.

## Conventions for references and abbreviations
- "Anm." → "Rem." (Remark) — set exactly where the print sets it; "Bemerkung." → "Observation."; "Folgerungen aus §. 12." → "Corollaries from § 12."; "Erläuterung." → "Elucidation."; "Probe" → "test"; "Beschluß" → "Conclusion"; "Nachtrag" → "Supplement"; "Vorrede" → "Preface"; "N. S." → "P.S.".
- "§." stays "§." with the number exactly as printed ("§. 12." → "§. 12."). "Num." → "No.".
- "d. i." → "i.e."; "z. B." → "e.g."; "u. s. w." / "u. s. f." → "etc."; "l. c." → "l. c."; "vergl." → "cf."; "S." / "Seit." → "p."; "ff." / "u. f." → "ff."; "Aufl." → "ed.".
- "Hr." / "Herr" before a name → "Mr"; "der Königsberger" → "the Königsberg man" (Kant, ironic).
- Names modernised in the English only: Friederich Nikolai → Friedrich Nicolai; Leibnitz → Leibniz; Loke → Locke; Kiesewetter, Maaß, Bilfinger, Ploucquet, Reinhold, Fichte, Schelling, Herder, Schlosser, Eberhard as normal; Epikur → Epicurus; Protagoras.
- Book titles in italics, translated: *Critique of Pure Reason*, *Metaphysical First Principles of the Doctrine of Right*, *Outline of Logic* (Maaß, *Grundriß der Logik*), Kiesewetter's *Outline of a General Logic*. Keep the edition/page references exactly.
- Latin: kept in italic as printed; complete sentences/verse get an English rendering in square brackets immediately after: *Cedo, qui vestram rempublicam tantam amisistis tam cito?* [Tell me, how did you lose so great a state so quickly?]. Stock terms (*per se*, *quid pro quo*, *modus ponens*, *terminus medius*, *conditio sine qua non*, *ens*, *verum*, *bonum*) need no gloss.
- Greek: keep as printed (fix only obvious non-word misprints).

## Style
- Bardili writes in sharp, sarcastic, compressed periods with dashes, parentheses and exclamations. Keep all of them;
  keep his parentheses nested as printed; keep "—" dashes.
- Keep his emphasis exactly: letter-spaced (Sperrdruck) words → <em>. (The print has no bold face; heavy-looking
  lines are just over-inked — never use <strong>.) Latin/French set in roman (Antiqua) type → <em> as well.
- British or American spelling: use **American** (-ize), but "judgment".
