# Glossary — Fries, *Neue Kritik der Vernunft* (1807) — BINDING

Standard: Cambridge Edition of Kant for shared Kantian vocabulary; Fries-specific terms as fixed below.
Keep a term identical every time it recurs; Fries's argument depends on it. If a term is missing here, choose
the Cambridge-Kant rendering and note it in your notes file.

## Title and book structure
- *Neue Kritik der Vernunft* = *New Critique of Reason*; Erster/Zweyter Band = Volume One/Two
- Half-title „Kritik der erkennenden Vernunft“ = “Critique of Cognizing Reason”; „Form der vernünftigen Erkenntniß oder Theorie der Einheit und Verbindung“ = “Form of Rational Cognition, or Theory of Unity and Combination”
- Vorrede = Preface; Einleitung = Introduction; Buch = Book; Abschnitt = Section; Kapitel = Chapter
- Erstes Buch: „Untersuchung des Erkennens überhaupt, der Sinnlichkeit und des gedächtnißmäßigen Gedankenlaufes“ =
  “Investigation of Cognizing in General, of Sensibility, and of the Memory-Bound Course of Thought”
- Zweytes/Drittes Buch: „Untersuchung des logischen Gedankenlaufes …“ = “Investigation of the Logical Course of Thought …”
- Anmerkung / Anm. = Remark / Rem.; Zusatz = Addendum; Erläuterung = Elucidation; Folgerung = Corollary;
  Lehrsatz = Theorem; Aufgabe = Problem; Beweis = Proof; Uebersicht = Survey; Beschluß = Conclusion
- Running signature line „Fries Kritik Iter Theil.“ / „II. Theil“ → keep EXACTLY as printed (German, untranslated;
  it is a printer's mark): `<p class="sig">Fries Kritik I^ter Theil.  3</p>` — see AGENT.md.

## Fries's triad and his central vocabulary
- Wissen = knowledge; wissen = know
- Glaube = faith; glauben = believe / have faith (choose by context; „Glaube“ as Fries's mode of conviction is always *faith*)
- Ahndung (= Ahnung) = intimation; ahnden = to intimate / have an intimation of; ahndungsvoll = full of intimation
- Ueberzeugung = conviction; Fürwahrhalten = holding-to-be-true
- unmittelbare Erkenntniß = immediate cognition; mittelbar = mediate
- Selbstvertrauen der Vernunft = the self-confidence of reason
- Wahrheitsgefühl = feeling for truth; Gefühl = feeling; Gefühlvermögen = faculty of feeling
- Selbsterkenntniß = self-cognition; Selbstbeobachtung = self-observation; innere Erfahrung = inner experience
- anthropologisch = anthropological; Anthropologie = anthropology; psychische Anthropologie = psychic anthropology
- Deduktion = deduction (Fries's sense: exhibiting a principle's origin in reason; NOT proof);
  Beweis = proof; Demonstration = demonstration; beweisen = prove; demonstriren = demonstrate; aufweisen = exhibit
- Besonnenheit = reflectiveness; besonnen = reflective; Reflexion = reflection; Wiederbeobachtung = re-observation
- Grundvorstellung = basic representation; Grundsatz = principle; Princip = principle; Grundmaxime = fundamental maxim
- Vorurtheil = prejudice (philosophical „Vorurtheil“ in the sense of a presupposition: still *prejudice*)
- Gedankenlauf = course of thought; gedächtnißmäßig = memory-bound; logisch = logical
- Spekulation = speculation; spekulativ = speculative; Raisonnement = reasoning
- Einheit und Verbindung = unity and combination; Verknüpfung = connection; verbinden = combine
- Theorie der Vernunft = theory of reason; Naturlehre = natural science / doctrine of nature (innere Naturlehre = inner natural science)
- Mythologie / Mysticismus = mythology / mysticism; Schwärmerey = enthusiasm (fanatical), Enthusiasmus = enthusiasm

## Faculties and mind
- Geist = mind (des menschlichen Geistes = of the human mind); but „Geist der Zeit“ = spirit of the age, Weltgeist = world-spirit,
  and *spirit* where contrasted with body or used religiously
- Gemüth = mind (if Geist and Gemüth stand together: Geist = mind, Gemüth = disposition of mind — note it)
- Seele = soul; Leben = life; Lebenskraft = vital force
- Vernunft = reason; vernünftig = rational; Verstand = understanding; Sinnlichkeit = sensibility; Sinn = sense;
  innerer/äußerer Sinn = inner/outer sense; Sinnesanschauung = sense intuition
- Erkenntnißvermögen = faculty of cognition; Vermögen = faculty; Kraft = power; Thätigkeit = activity;
  Selbstthätigkeit = self-activity; Spontaneität = spontaneity; Receptivität / Empfänglichkeit = receptivity
- Einbildungskraft = imagination; Phantasie = fantasy; Gedächtniß = memory; Erinnerung = recollection;
  Association/Ideenassociation = association (of ideas); Aufmerksamkeit = attention; Bewußtseyn = consciousness
- Begehrungsvermögen = faculty of desire; Begierde = desire; Trieb = drive; Wille = will; Willkühr = choice (power of choice);
  Neigung = inclination; Interesse = interest; Zweck = end (purpose where idiomatic)
- Urtheilskraft = power of judgment; Witz = wit; Scharfsinn = acumen

## Cognition and its objects
- Erkenntniß = cognition (pl. cognitions); Erkennen = cognizing / cognition (activity); erkennen = cognize
  (use “know”/“recognize” only where the context is plainly non-technical); Kenntniß = knowledge (acquaintance) → “knowledge”, note if paired with Wissen
- Vorstellung = representation; vorstellen = represent; sich vorstellen = represent to oneself
- Anschauung = intuition; anschaulich = intuitive; anschauen = intuit
- Begriff = concept; Urtheil = judgment; Schluß = inference; Vernunftschluß = syllogism; Satz = proposition
- Wahrnehmung = perception; Empfindung = sensation; Eindruck = impression; Affektion = affection
- Gegenstand = object; Objekt = object; objektiv/subjektiv = objective/subjective
- Erscheinung = appearance; Ding an sich = thing in itself; Sache = thing / matter; Ding = thing
- Mannigfaltiges = manifold; Synthesis = synthesis; Apperception = apperception; Kategorie = category;
  Schema/Schematismus = schema/schematism; Form/Materie = form/matter; Stoff = material
- a priori / a posteriori (italic); transcendental = transcendental; transcendent = transcendent; empirisch = empirical; rein = pure
- Nothwendigkeit = necessity; Allgemeinheit = universality; Möglichkeit/Wirklichkeit = possibility/actuality; Daseyn = existence; Seyn = being
- Substanz, Ursach(e), Wirkung, Wechselwirkung = substance, cause, effect, interaction; Beharrlichkeit = persistence; Kausalität = causality
- Größe = magnitude; Grad = degree; Raum/Zeit = space/time; Gestalt = figure
- Idee = idea; Ideal = ideal; Wahrheit = truth; Irrthum = error; Schein = illusion
- Wahrscheinlichkeit = probability; Gewißheit = certainty; Evidenz = evidence (self-evidence)
- Naturnothwendigkeit = natural necessity; Nothwendigkeit der Natur = necessity of nature
- Erklärung = explanation (definition where it is a logical definition: „Erklärung“ in logic = definition — choose by context and note)
