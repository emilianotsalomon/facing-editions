# Notes and annotations

One `notes.md` per text, inside the text's folder: `corpus/exner-psychologie-hegelsche-schule/notes.md` annotates that edition;
`corpus/vasconcelos/vasconcelos-1925-la-raza-cosmica/notes.md` annotates the Vasconcelos edition of that name.
(For a text still kept as one interleaved file, `corpus/notes/<same name and sub-folder>.md` is read instead.)

Inside the file, a heading opens each note. A heading that names a page attaches the note to that page in the reader:

```
## [p. 154] The missing §§ 220–223
These four pages are absent from the UC scan and were spliced in from the BSB copy. — ES, Oct 2026

## General remark
A note without a page number appears at the top of the text's page.
```

Write page numbers as the folio reads in the text (`[p. I.41]` for the Exner Hefte, `[p. xii]` for roman folios).
Emphasis `*…*`, bold `**…**`. Sign notes with initials and a date so a reader knows whose voice it is.

Longer working documents that are not tied to one text (concordances, reading notes across several works) can
have any name; they are not shown in the reader but they are part of the Claude Project's knowledge.

To add or edit a note on the GitHub website: open the file, click the pencil, edit, write a one-line summary,
**Commit changes**. The reader rebuilds itself within a minute or two.
