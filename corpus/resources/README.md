# Machine Study Resources

Supplements to the primary texts: study guides, concordances, reading notes, term lists, chronologies, summaries — anything that helps the reading but is not itself an edition. One Markdown file per document. They appear in the reader under **Machine Study Resources** and go into the Claude Project together with the texts.

Start a file with a short header so the reader can list it:

```
---
title: Concordance of repeated passages in Vasconcelos
author: ES
about: vasconcelos
kind: concordance
---
```

`about` names the text or author it supplements (free text); `kind` is a word of your choice (study guide, concordance, notes, glossary…). Files without a header are listed by their first heading. Add or edit them on the GitHub website (pencil icon, Commit changes) or through GitHub Desktop; the reader rebuilds itself.
