# General glossary — German philosophy → English

The group's general default for translating German philosophical prose. It applies wherever a book's own glossary (`corpus/glossaries/<book>.md`) is silent; where a book's own glossary rules a term differently, the book's glossary wins. Companion files: `_general-spanish-to-english.md`, `_translation-style-guide.md`.

Seeded with the standard scholarly English terminology used by Kant translators
(the Cambridge Edition / Guyer–Wood conventions) and the common Hegel conventions.
These are the *defaults*; when the group's own aligned German editions (Klages,
Conrad-Martius, Walther, etc.) settle a term differently, that choice overrides
the default here — record it with the source.

The single most important discipline in German philosophy translation is
**one German term ⇄ one English term** for the technical vocabulary, so the
argument's structure survives. The traps below are where translations usually
break.

## Terms flagged for an original-term footnote (FN) — STANDALONE editions only

⚠️ These flags are **inert in side-by-side / parallel editions** (the original is
in the facing column). They fire **only** in a standalone English-only edition —
see `style-guide.md` → "Original-term footnotes." **FN ✓** = first occurrence per
chapter; **FN ✓ (every)** = every occurrence. This is the master list the workflow
checks when (and only when) it's producing a standalone edition.

| German | English | FN | Footnote content |
|---|---|---|---|
| Zweckmäßigkeit | **purposiveness** | ✓ | *Zweckmäßigkeit* |
| Aufhebung | **sublation** | ✓ | *Aufhebung* (cancel-and-preserve) |
| Sittlichkeit | **ethical life** (Hegel) / **morality** (Kant) | ✓ | *Sittlichkeit* |
| Anschauung | **intuition** | ✓ | *Anschauung* |
| Erkenntnis | **cognition** | ✓ | *Erkenntnis* |
| Geist | **spirit** | ✓ | *Geist* |
| Dasein | **determinate being** / **existence** | ✓ | *Dasein* |
| Vorstellung | **representation** | | *Vorstellung* — unflagged; flag if a work leans on it |

To flag any other row in the tables below, add **FN ✓** in its Note column.

## Hegel-era / broader idealism (dialect shifts)

| German | English (ruling) | Note / trap |
|---|---|---|
| Geist | **spirit** | Capitalize when it names the metaphysical subject; *Phänomenologie des Geistes* → *Phenomenology of Spirit*. |
| Aufhebung / aufheben | **sublation / to sublate** | Keep *Aufhebung* [sublation] on first use; the term carries cancel-and-preserve. |
| an sich / für sich / an und für sich | **in itself / for itself / in and for itself** | |
| Sittlichkeit | **ethical life** | ⚠️ Hegel-specific, opposed to *Moralität*. |
| Moralität | **morality** | (Hegel: the standpoint of individual conscience) |
| Wesen | **essence** / **being** | "essence" for *Wesen* as ground; "being" only where the concrete-entity sense is clear. Decide per context, note it. |
| Dasein | **existence** / **determinate being** | Hegel: "determinate being." Keep *Dasein* untranslated only in explicitly Heideggerian material. |
| Begriff | **the Concept** | In Hegel, capital-C "Concept" (older translations: "the Notion"). |
| Vorstellung | **representation** / **picture-thinking** | Hegel sometimes pejorative ("picture-thinking"); note when so. |
| Wirklichkeit | **actuality** | Not merely "reality" (*Realität*). |

## Kept-in-original / Latin
*a priori*, *a posteriori*, and any term the author coins or scare-quotes:
keep the original in italics, with a bracketed gloss on first use.

## Proper names — leave as in source
Kant, Hegel, Fichte, Schelling, Husserl, etc. Do not anglicize.
