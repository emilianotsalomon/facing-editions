# General glossary — Spanish philosophy → English

The group's general default for translating Spanish-language philosophical prose. It applies wherever a book's own glossary (`corpus/glossaries/<book>.md`) is silent; where a book's own glossary rules a term differently, the book's glossary wins. Companion files: `_general-german-to-english.md`, `_translation-style-guide.md`.

Authoritative source: the group's finished editions. Seeded from Deustua,
*La estética contemporánea* (1924). "Ruling" = the fixed English choice;
"Note" explains why and warns of the tempting wrong choice.

## Core terms

| Spanish | English (ruling) | Note |
|---|---|---|
| espíritu | **spirit** | Not "mind." Deustua opposes *espíritu* to *materia*; "spirit" carries the metaphysical weight. Capitalize *Espíritu* → *Spirit* when he does. |
| alma | **soul** | Keep distinct from *espíritu*. "el alma del alma" → "the soul of the soul." |
| libertad | **freedom** | Default to "freedom" (the value/principle). Use "liberty" only if a political-rights sense is unmistakable. |
| orden | **order** | Load-bearing in Deustua (order ↔ freedom). Never "arrangement." |
| valor | **value** | Capital-V **Value** when used as the technical della Valle category ("el Valor"). |
| valuación | **valuation** | The act of applying a value-category. Not "evaluation." |
| creación | **creation**; creador/a → **creative** | "imaginación creadora" → "creative imagination." |
| imaginación inventiva | **inventive imagination** | Distinguish from *imaginación creadora* → creative imagination; both appear. |
| intuición | **intuition** | |
| sentimiento | **sentiment** / **feeling** | "sentiment" when paired with reason/intellect as a faculty; "feeling" for the affective state. Pick per sentence, stay consistent within a passage. |
| voluntad | **will**; voluntad libre → **free will** | |
| devenir | **becoming** | Bergsonian. Not "future" or "evolution." |
| Deber Ser | **Ought-to-Be** | Capitalized, hyphenated, as a noun. |
| Yo-sujeto / Yo-objeto | **I-Subject / I-Object** | Keep the hyphenated compound; capital I. |
| no-coacción | **non-coercion** | Hyphenated. |
| goce | **joy** | "goce inefable" → "ineffable joy." |
| nota (de) | **mark / characteristic** | ⚠️ NOT "note." Scholastic *nota* = a defining feature. "son notas de la imaginación" → "are marks of the imagination." |
| pancalismo | **pancalism** | ⚠️ NOT "panlogism." Baldwin/Ravaisson doctrine that all reality is aesthetic/beautiful. Distinct from *panlogismo* (panlogism, Hegelian). |
| armonía | **harmony** | |
| equilibrio | **equilibrium** | "equilibrio estático" → "static equilibrium." "balance" acceptable only where non-technical. |
| facultades cognoscitivas | **cognitive faculties** | |
| conciencia | **consciousness**; conciencia mística → **mystical consciousness** | "conscience" only for the moral sense, which Deustua rarely means. |
| reviviscencia | **reviviscence** | Keep the technical cognate (revival of a memory-image). |
| adivinación (de valores) | **divination** | "divination of values." |
| pensamiento | **thought** | |

## Proper names — leave as in source
Bergson, Ravaisson, Wundt, Ribot, Brunschvicg, Schelling, Baldwin,
Guido della Valle. Do not anglicize.
